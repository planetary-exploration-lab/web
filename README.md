# Planetary eXploration Lab website

Static Astro site for the Planetary eXploration Lab (PXL) at Georgia Tech. It builds to plain files,
deploys to GitHub Pages, and loads nothing from third parties.

Project status and planning notes are kept in the private companion repository.

## Run it locally

Requires Node 22.23.4 or newer (CI uses the version in `.nvmrc`) and Python 3.

```sh
npm ci
npm run setup:browser        # once: Chromium for the accessibility check
npm run dev                  # http://localhost:4321/en/
npm run build && npm run check
```

Set `BASE_PATH=/web/` to build exactly as the preview site is served.

## Where things live

| What | Where |
| --- | --- |
| Projects | `src/content/projects/<id>.md` (translations in `es/`, `fr/`, `ja/` subfolders, same file name) |
| News | `src/content/news/<date>-<slug>.md` |
| Publications | `src/data/publications.yaml`, generated by `scripts/sync_publications.py` (never edit by hand), plus optional `src/content/publications/<id>.yaml` for featured order, summary and project links |
| Gallery | `src/data/gallery.yaml` and `src/assets/gallery/` |
| Contact routes | `src/data/routes.yaml` |
| UI text | `src/i18n/<lang>.json` |
| Colors and type | `src/styles/tokens.css` |
| Old-site redirects | `src/data/redirects.yaml` (plus each project's `legacyUrl`) |
| Images | `src/assets/`; prepare with `scripts/prepare_images.mjs`, see [docs/images.md](docs/images.md) |
| People | `planetary-exploration-lab/web-private` only. Local and PR builds use the fake records in `fixtures/people/`. |

Schemas for every content type are in `src/content.config.ts`. A missing required field, missing alt
text or unknown ID fails the build.

## Privacy

Never commit real people data, photos, unpublished manuscripts, keys or contact details to this repo.
People data lives in `web-private`, and the site shows only the fields each person has consented to.

Before every commit, run `npm run check:private` (or `python3 -I scripts/check_private.py --staged`). It fails on
token patterns, private keys, 1Password references, real-looking emails and phone numbers, person records outside
`fixtures/people/`, images with EXIF metadata, and env or key files.

## Checks

`npm run check` runs, against `dist/`:

- `astro check` (types and content)
- `html-validate` on every page
- `scripts/check_dist.py`: external-origin scan, internal links, `lang`, alt attributes, CSP
- `scripts/check-a11y.mjs`: axe-core WCAG 2.2 AA on every page in all languages, light and dark
